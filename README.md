# Tá Ligado?

Bem-vindo! Este arquivo mostra o essencial para instalar e testar o APK rapidamente.

# 1) Instalação do APK
•
Instalação direta: transferir o APK e tocar para instalar. Permita “Instalar de fontes desconhecidas” se solicitado.
Se a instalação falhar por assinatura, remova versão anterior antes:
Configurações do Android → Aplicativos → Tá Ligado? → Desinstalar

# 2) Versão Android recomendada
•
Recomendado: Android 9.0 (API 28) ou superior.

# 3) Permissões necessárias
•
Armazenamento: usado para carregar arquivos externos (quando aplicável).

# 4) Conceito e Objetivo
•
Tá Ligado? é um jogo mobile de cartas estratégicas sobre eficiência energética e sustentabilidade. O jogador atua como técnico do programa “Ta ligado?”, visitando residências, escolas, comércios e estádios para diagnosticar desperdícios e aplicar soluções que reduzam consumo e tornem a cidade referência em sustentabilidade.
Mecânica Principal
Cada fase apresenta problemas (fontes de desperdício) e uma mão de cartas de solução. Cada carta tem custo e potencial de economia. O desafio é combinar soluções para atingir metas de redução sem estourar o orçamento. Sistema de afinidades e combos torna certas soluções mais eficazes contra problemas específicos.

# 5) Como a sustentabilidade está aplicada?
•
O conteúdo (problemas e soluções) baseia-se em práticas reais de eficiência energética: LED, manutenção HVAC, sensores, motores eficientes, isolamento, otimização de horários, etc. O jogo educa por meio da mecânica: cada melhoria representa uma ação concreta para reduzir consumo e impactos ambientais.


# 6) Instruções de como jogar (resumo)
•
Ler o problema do local (desperdício atual, metas e orçamento).
Selecionar cartas de solução da mão e aplicá-las sobre os problemas com melhor custo-benefício.
Usar embaralhar estrategicamente (custa orçamento) para buscar soluções mais adequadas.
Long-press em cartas para ver detalhes; abrir tutorial para aprender mecânicas.
Vencer reduzindo todos os problemas antes de ficar sem orçamento; perder ocorre quando o orçamento não permite resolver os problemas restantes.

# 7) Primeiro acesso / Intro (A ser implementada...)
•
Na primeira vez, o intro em vídeo tocará automaticamente (se o vídeo estiver presente).
Para reassistir: Menu → História (botão “História”).

# 8) Tutorial
•
Pode ser aberto a qualquer momento no HUD pelo botão “Ajuda/Tutorial” nas configurações durante uma fase.
O tutorial é um carrossel de imagens (Próxima / Anterior / Fechar).

# 9) Controles rápidos
•
Tap em carta: seleciona solução.
Tap em problema: aplica solução selecionada.
Long-press (1.5s) numa carta: abre painel de zoom (cartão maior, só leitura).
Botão Embaralhar: troca a mão por um custo (olhe o HUD).
Botões do menu: História = rever intro; Ajuda = tutorial; Config = ajustes de áudio etc.

# 10) Feedback visual e sonoro
•
Solução correta: problema pisca verde e some; som de vitória ao completar nível.
Solução errada: problema pisca vermelho.
Você pode ajustar volumes em Configurações (no menu).

# 11) Requisitos mínimos (recomendado para teste)
•
CPU: quad-core ~1.5 GHz.
RAM: 2 GB (4 GB recomendado).
GPU: OpenGLES 3.0 compatível.
Espaço livre: ~150 MB .
